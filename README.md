# Covid-19 Data Exploration (SQL)

An analysis of Covid-19 data using SQL. I wrote queries to explore cases, deaths, and trends across countries and over time.

## Questions I explored
- How did total cases change over time?
- Which countries had the highest number of cases and deaths?
- What was the death rate compared to total cases?
- How do numbers compare across regions?

## Tools
- **SQL** for querying and analysis
- **CSV** data files

## What's in this repo
- `.sql` files: the queries I wrote
- `.csv` files: the data I analysed

## How to use it
1. Load the CSV files into a SQL database (like MySQL, PostgreSQL, or SQL Server).
2. Run the `.sql` files to reproduce the analysis.

## Skills shown
Data exploration, filtering, grouping, aggregation, and turning raw data into insights.
